# DeepCore — پروژه جست‌وجوی هوش مصنوعی

این مخزن برای درس «مبانی و کاربردهای هوش مصنوعی» آماده شده است. هدف، مدل‌سازی مسئله‌ی نجات معدنچی‌ها و پیاده‌سازی الگوریتم‌های جست‌وجوی ناآگاهانه و آگاهانه است.

راهنمای کامل دانشجو در [docs/student-guide-fa.md](docs/student-guide-fa.md) و مشخصات رسمی و تصویری مسئله در [docs/assignment.html](docs/assignment.html) قرار دارد.

## شروع سریع دانشجو

به Python 3.10 یا بالاتر نیاز دارید. پس از استخراج فایل پروژه، از ریشه‌ی آن فقط این دستور را اجرا کنید. این دستور وابستگی‌های فایل `requirements.txt` را به‌صورت خودکار نصب می‌کند. برای سازگاری با Python 3.14، پروژه از `pygame-ce` استفاده می‌کند که همچنان با `import pygame` در کد کار می‌کند:

```powershell
python main.py
```

منوی بازشده، اجرای نمونه‌ی BFS، آزمون‌ها، رابط گرافیکی و راهنما را در اختیار شما می‌گذارد. برای اجرای مستقیم یک الگوریتم نیز می‌توانید بنویسید:

```powershell
python main.py --algo bfs --map level1
python main.py --algo astar --map level2 --heuristic h1
```

الگوریتم‌های جستجو (نظیر IDS، Bidirectional و IDA*) در حالت پیش‌فرض بدون سقف و محدودیت مصنوعی اجرا می‌شوند تا همواره به جواب قطعی برسند (`metrics.solved = True`). در صورتی که فراخوان به صورت عمدی آرگومان‌های سقف عمق (`max_depth`) یا سقف بسط‌ها (`max_expansions`) را ارسال کند، جستجو محدود شده و در صورت رسیدن به سقف، وضعیت با پیام `Expansion limit reached.` گزارش خواهد شد.

برای رابط گرافیکی، گزینه‌ی ۳ منو یا دستور زیر را اجرا کنید؛ وابستگی گرافیکی نیز خودکار نصب می‌شود:

```powershell
python main.py --gui
```

## نقشه‌ی مخزن

```text
src/deepcore/          کد اجرایی پروژه
  solver.py            فایل اصلی پیاده‌سازی دانشجو
  heuristics.py        فایل پیاده‌سازی هیوریستیک دانشجو
  environment.py       محیط و قوانین مسئله — تغییر ندهید
  state.py             مدل immutable حالت و SearchMetrics — تغییر ندهید
  visualizer.py        رابط گرافیکی — تغییر ندهید
tests/                 آزمون‌های عمومی دانشجو
docs/                  راهنما و مشخصات تکلیف
assets/                تصاویر رابط گرافیکی
```

دانشجو فقط `src/deepcore/solver.py` و `src/deepcore/heuristics.py` را تغییر می‌دهد. فایل‌های محیط، حالت، رابط گرافیکی و آزمون‌ها قرارداد پروژه را تعریف می‌کنند و نباید تغییر کنند.

## تحویل

نسخه‌ی تحویلی باید شامل تغییرات دو فایل دانشجویی، `Report.pdf` و هر فایل کمکی مجاز باشد. قبل از تحویل، آزمون‌های عمومی را اجرا کنید و جدول مقایسه‌ی الگوریتم‌ها را در گزارش وارد کنید.
